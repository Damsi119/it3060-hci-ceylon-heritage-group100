# Ceylon Heritage
### Historical Walking-Tour Route Planner Mobile App

Ceylon Heritage is a mobile application designed to help users discover Sri Lanka’s historical places, plan multi-destination heritage tours, and share their travel experiences.

The project is developed for the **IT3060 – Human Computer Interaction** module at the **Sri Lanka Institute of Information Technology (SLIIT)** by **Group Y3S2_WE_100**.

---

## Project Overview

Exploring historical destinations often requires users to switch between different tools for place information, route planning, weather updates, and travel recommendations.

Ceylon Heritage brings these activities together in one mobile experience. The application focuses on clear navigation, accessible information, and convenient tour planning to support heritage exploration.

## Project Objectives

- Help users discover historical places and understand their cultural significance.
- Support historical place searches and detailed destination information.
- Allow users to create tours containing multiple destinations.
- Provide a community space for sharing heritage travel experiences.
- Support route previews, navigation, and tour progress tracking.
- Provide useful travel information, including nearby facilities and weather.

## Human Computer Interaction Focus

The project applies HCI principles throughout its interface design and development:

- **Consistency:** Familiar layouts, colours, and navigation patterns.
- **Visibility:** Clear actions, status indicators, and tour progress.
- **Feedback:** Responses to user actions, including loading, success, and error states.
- **User control:** Opportunities to review and adjust selections.
- **Error prevention:** Input validation and confirmation for important actions.
- **Readability:** Clear typography, meaningful labels, and suitable contrast.

## Local Development

### Prerequisites

- Flutter SDK and Dart.
- A Java version compatible with the backend project.
- PostgreSQL.
- Git.
- Android Studio or another Flutter-compatible IDE.
- IntelliJ IDEA or another Java-compatible IDE.

### Setup Overview

1. Clone this repository.
2. Configure a local PostgreSQL database.
3. Configure the backend database connection and required environment settings.
4. Start the Spring Boot backend.
5. Install Flutter dependencies using `flutter pub get`.
6. Configure the frontend API base URL for the selected device.
7. Run the Flutter application using `flutter run`.

The API base URL depends on whether the application runs in a browser, Android emulator, or physical device.

Keep passwords, API keys, tokens, and other credentials out of version control.
